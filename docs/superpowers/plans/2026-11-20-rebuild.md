# Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One dark dashboard on every page, two stock-picking paper bots, and three competing hype rule sets.

**Architecture:** The simulation core, safety layer and stores stay. A second runner (`InPlayRunner`, a subclass of `IntradayRunner`) trades a per-day symbol list chosen by a morning scan. The hype runner drives several accounts over one shared, cached feed. Every page renders through one shell and one stylesheet.

**Tech Stack:** Python 3.12, standard library only, server-rendered HTML with inline SVG, PostgreSQL via psycopg.

**Spec:** `docs/superpowers/specs/2026-11-20-rebuild-design.md`

## Global Constraints

- No brokerage code, no new network host (`safety/endpoints.py` allowlist is not edited).
- Tiingo budget: limiter 45 requests/hour; never block the ETF bots' commit.
- Parameters are round numbers fixed up front; nothing tuned.
- `ruff check src tests` adds no new findings; `python -m unittest discover -s tests -t .` passes.
- No PostgreSQL on the build machine: new SQL copies idioms already in the file it is added to, and is flagged as verified only by CI.

## Review Focus

- A day with no picks (missed scan, nothing gapped): both in-play bots commit a flat day, pages render.
- A pick with thin IEX data (few bars): the core excludes it; the bot page says why.
- A stock with fewer than 10 sessions of history: `sip_odds` skips it with a visible reason.
- Tiingo ignores the `tickers` filter and returns every symbol: the scan still filters to the universe.
- No database yet / hype bot off / market closed: every page renders through the new shell.

### Task 2: Stocks in play

**Files:** Create `src/tradinglab/intraday/universe.py`, `intraday/inplay.py`, `intraday/replay.py`, `tests/test_inplay.py`. Modify `intraday/strategies.py`, `intraday/core.py`, `intraday/live.py`, `marketdata/tiingo.py`, `engine/intraday_store.py`, `engine/pg_intraday.py`, `engine/runtime.py`, `web/server.py`, `web/views_bots.py`.

**Interfaces — produces:**
- `universe.IN_PLAY: tuple[str, ...]` (about 100 liquid US stocks, upper case, no ETFs)
- `TiingoClient.iex_quotes(tickers: Sequence[str]) -> list[dict]` (`GET /iex/?tickers=a,b,c`; one request)
- `inplay.pick(quotes: Iterable[Mapping], universe: Collection[str], *, min_gap=0.01, min_price=5.0, top=5) -> list[Pick]`; `Pick(symbol, gap, last, open, prev_close)`. Qualifies when `open/prev_close - 1 >= min_gap`, `last > open`, `last >= min_price`; ranked by gap, ties by symbol.
- Store: `save_picks(universe: str, day: date, payload: dict) -> None`, `picks(universe: str, day: date) -> dict | None`; payload `{"at": iso, "scanned": int, "picks": [...], "note": str}`.
- `BotSpec(id, strategy_id, params, universe="etf", name="", summary="", rules=())` with `title`, `blurb`, `rule_lines` properties falling back to the strategy's.
- `live.DEFAULT_BOTS` becomes the explicit seven ETF bots; `inplay.IN_PLAY_BOTS = (sip, sip_odds)`.
- `IntradayRunner.core/bars_for/prev_closes/history` take an optional `symbols`; `IntradayRunner.symbols_on(day) -> list[str]`.
- `InPlayRunner(settings, store, fetch_rows, fetch_quotes, bots=IN_PLAY_BOTS, universe=IN_PLAY, budget=lambda: 999)`: scan window open+3min to open+15min; history load 15 sessions per pick; display refresh inside 6 requests/hour; commit after the close; run-lock name `inplay`.
- `strategies.Skip(reason: str, diagnostics: Mapping[str, float])` — the core records it as an `ISignal(action="skip", outcome="rejected")`.
- `strategies.OrbOdds` (`id="orb_odds"`, `history_days=15`, defaults `range_minutes=15, min_exp_r=0.1, min_sessions=10, paths=2000`).
- `replay.replay(history, session_open_of, after_minute, entry, stop, *, paths, seed) -> Odds | None`; `Odds(p_stop, p_up, exp_r, sessions, paths)`.

- [ ] Tests: `pick` rules and ordering; quotes for symbols outside the universe ignored; missed scan stores an empty pick list and commits a flat day; scan happens once per day; commit uses the stored picks even if quotes change later; `replay` is repeatable for a seed and returns None under 10 sessions; `OrbOdds` skips with a reason when the replay is below the bar and enters with odds in diagnostics when above; ETF bots' results are byte-identical before and after (existing tests).
- [ ] Wire `InPlayRunner` into `build_state` and the scheduler's extra jobs; history tests skip in-play bots.
